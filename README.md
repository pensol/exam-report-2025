# 2025年度 入試受験レポート Web入力版

未記入の受験レポートを背景に、PC・スマートフォンから文字入力や選択ができる静的Webフォームです。

公開サイト: <https://pensol.github.io/exam-report-2025/>

## 主な機能

- PDF座標を基準にした入力位置
- 文字、数字、複数行入力
- クリック／タップによる○印
- スマートフォン用の縦並び入力画面
- 入力内容の端末内自動保存
- 元PDF実寸での印刷・PDF保存
- 座標デバッグ表示

## データの扱い

入力内容はブラウザの `localStorage` に保存されます。GitHubや外部サーバーへ送信する処理はありません。別の端末とは自動同期されず、ブラウザのサイトデータを削除すると入力内容も消去されます。

## 座標調整

入力欄は `fields.js` にPDFポイント・左上原点で定義されています。○印の大きさは `style.css` の `.mark::after` で調整できます。
